# SCADA Generator - Modbus TCP Клиент
Многофункциональное безопасное приложение для работы с устройствами Modbus 
TCP  с расширенной системой логирования в базе данных PostgreSQL.

## 🛡️ Особенности безопасности
- **Защищенные пароли** через переменные окружения
- **Конфиденциальные данные** исключены из репозитория
- **Безопасное подключение** к базе данных
- **Шаблон конфигурации** для безопасной настройки

## 🚀 Основные возможности
### 🔌 Modbus TCP Клиент
- **Подключение** к устройствам Modbus TCP
- **Чтение данных**: дискретные входы, катушки, регистры
- **Запись данных**: одиночные катушки, регистры
- **Мониторинг** в реальном времени
- **Графическая визуализация** состояния устройств

### 💾 Система логирования в PostgreSQL
- **Автоматическое создание** базы данных и таблиц
- **Логирование всех операций** чтения/записи
- **Запись попыток подключения** с результатами
- **Измерение времени выполнения** операций
- **Статистика** успешных/неудачных операций

### 🎛️ Пользовательский интерфейс
- **Интуитивно понятный** графический интерфейс
- **Визуализация состояния** дискретных входов
- **Журнал операций** в реальном времени
- **Панель статуса** подключения
- **Управление конфигурацией**

## 🗄️ Структура базы данных
### Таблица `usage_parameters`
Хранит информацию о всех операциях с Modbus устройствами:
| Поле | Тип | Описание |
|------|-----|----------|
| id | SERIAL | Первичный ключ |
| timestamp | TIMESTAMP | Время операции |
| operation_type | VARCHAR(50) | Тип операции |
| device_id | INTEGER | ID устройства Modbus |
| address | INTEGER | Адрес регистра |
| value | VARCHAR(100) | Значение |
| result | VARCHAR(500) | Результат операции |
| duration_ms | INTEGER | Время выполнения (мс) |
| success | BOOLEAN | Успешность операции |

### Таблица `connection_configs`
Хранит историю подключений:
| Поле | Тип | Описание |
|------|-----|----------|
| id | SERIAL | Первичный ключ |
| timestamp | TIMESTAMP | Время подключения |
| host | VARCHAR(100) | Хост устройства |
| port | INTEGER | Порт устройства |
| slave_id | INTEGER | ID устройства Modbus |
| connection_success | BOOLEAN | Успешность подключения |
| error_message | TEXT | Сообщение об ошибке |

## 🛠️ Установка и запуск
### Предварительные требования
1. **Python 3.8+**
2. **PostgreSQL 12+**
3. **Устройство Modbus TCP** (опционально для тестирования)

### Быстрый старт
# 1. Клонируйте репозиторий
git clone <repository-url>
cd SCADA_Generator
# 2. Настройте переменные окружения
Copy-Item .env.example .env
# Отредактируйте .env файл с вашими настройками
# 3. Установите зависимости
pip install -r requirements.txt
# 4. Настройте базу данных
python setup_database.py
# 5. Запустите приложение
python main.py

Детальная установка
1. Настройка переменных окружения
Создайте файл .env на основе .env.example:
# .env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=scada_generator
DB_USER=avser
DB_PASSWORD=ваш_сложный_пароль_здесь
2. Установка зависимостей
bash
pip install -r requirements.txt
3. Настройка базы данных
bash
python setup_database.py
Следуйте инструкциям скрипта для настройки PostgreSQL.
4. Запуск приложения
bash
python main.py
Или используйте скрипт запуска PowerShell:
powershell
.\start.ps1

🔧 Конфигурация
Файл config.json
Создается автоматически при первом запуске:
json
{
  "host": "192.168.0.1",
  "port": 502,
  "slave_id": 1
}
Переменные окружения
Все конфиденциальные данные хранятся в .env файле:
DB_HOST - хост PostgreSQL
DB_PORT - порт PostgreSQL
DB_NAME - имя базы данных
DB_USER - пользователь БД
DB_PASSWORD - пароль БД

📊 Использование
Подключение к устройству Modbus
Введите параметры подключения:
Хост: IP-адрес устройства
Порт: 502 (стандартный порт Modbus)
ID устройства: Slave ID устройства
Нажмите кнопку "Подключиться"

Операции чтения
Чтение дискретных входов - чтение битовых входов
Чтение катушек - чтение битовых выходов
Визуализация - графическое отображение состояния

Операции записи
Запись катушки - установка значения отдельной катушки
Укажите адрес и значение (0/1)

Мониторинг
Запуск мониторинга - автоматическое чтение данных
Обновление в реальном времени - каждую секунду
Визуальное отображение изменений состояния

🔒 Безопасность
Проект использует следующие меры безопасности:
Пароли БД хранятся в .env файле
.env добавлен в .gitignore
Используются безопасные методы подключения к БД
Конфиденциальные данные исключены из репозитория

🐛 Устранение неполадок
Ошибки подключения к БД
Убедитесь, что PostgreSQL запущен
Проверьте правильность параметров в .env файле
Запустите скрипт настройки БД заново
Ошибки подключения к Modbus
Проверьте сетевые настройки
Убедитесь, что устройство доступно
Проверьте правильность Slave ID
